# NEXORA — Robotics & Engineering

Building ideas into reality through technology, engineering, and innovation.

NEXORA is a modern robotics and engineering website designed to showcase the possibilities of robotics, intelligent automation, mechanical design, and emerging technologies. I built this project to explore modern web design while creating a futuristic digital experience with smooth animations and an interactive interface.

The website combines a clean layout, a dark visual theme, and subtle motion effects to give it the feel of a technology-focused engineering studio.

## What’s Inside

- A futuristic landing page with animated visuals and statistics
- An About section highlighting robotics and engineering
- Service cards for robotics design, CAD, prototyping, and automation
- A project gallery showcasing engineering concepts
- A contact section for project inquiries
- Responsive navigation for mobile and desktop
- Smooth scrolling, hover effects, and scroll-reveal animations

## Tech Stack

I kept the project simple and built it using the core frontend technologies:

- **HTML5** — to structure the website
- **CSS3** — for custom styling, animations, and visual effects
- **JavaScript** — for interactive elements and dynamic behavior
- **Tailwind CSS** — for responsive layouts and utility-based styling

No React, Next.js, or additional JavaScript frameworks are used.

## Run It Locally

Getting started is straightforward.

1. Clone this repository or download the project files.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension if you haven't already.
4. Right-click `index.html` and select **Open with Live Server**.

That's it — the website should open in your browser.

An internet connection is required for the Tailwind CSS CDN and the external images used in the demo.
